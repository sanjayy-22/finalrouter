# Data formats

## `queries.jsonl` (one query per line)
| field | required | meaning |
|---|---|---|
| `query_id` | yes | unique id |
| `prompt` | yes | text sent to every model |
| `task_category` | yes | one of `qa, reasoning, coding, summarization, writing, extraction, instruction` |
| `split` | yes | `dev` (tuning, warm-up, normalization ranges, rules) or `test` (reported results) |
| `scorer` | yes | `exact`, `choice`, `numeric`, `contains`, `unittest`, `judge` |
| `reference` | for exact/choice/numeric | reference answer (string, list of strings, or GSM8K-style `#### 42`) |
| `required` | for contains | list of strings that must appear |
| `tests` | for unittest | Python test code appended after the extracted code block |
| `rubric` | for judge | grading rubric |

See `queries.example.jsonl`. Check the license of every dataset you import.

## `outcomes.jsonl` (one row per query × model), written by `evaluation/collect.py`
`query_id, model_id, task_category, split, response, quality_score (0-1 or null), failed, error,
latency_ms, input_tokens, output_tokens, cost`

`data/synthetic/` is generated by `evaluation/synth.py` and is **not** real data.
